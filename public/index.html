검사 범위와 데이터 갱신 안내

Upptime이 공개 건강 확인 주소의 HTTP 상태와 응답 내용을 검사합니다. 장애·지연이 감지되면 재시도 후 기록하며, 상태가 바뀔 때 이메일을 준비합니다. 메일 서버가 수락한 결과와 실제 받은편지함 도착은 다릅니다.

채팅·운영 서버의 HTTP 응답은 실제 WebSocket 메시지 전달이나 정산 작업 완료를 증명하지 않습니다. Pi 로그인·송금·보이스챗 실제 사용도 별도 확인이 필요합니다.

공급자 사용량·한도 알림은 위 공식 설정에서 확인합니다. 외부 검사 결과가 20분 이상 갱신되지 않으면 ‘검사 지연’으로 표시합니다. GitHub 예약 실행과 원본 파일 캐시에 지연이 있을 수 있습니다.
